# Импорт XLSX

## Формат колледжа

Выберите «Расписание колледжа» в `/admin/schedule/importbatch/upload/`. Исходный XLSX не нужно преобразовывать: периоды берутся из шапки, две недели и подгруппы — из блоков с объединёнными ячейками. Пустые вспомогательные листы пропускаются. Допустимы курсы 1–4.

Профиль автоматически создаёт явно указанные в файле группы, преподавателей, дисциплины и кабинеты при подтверждении. Предпросмотр не сохраняет справочники. Кабинеты остаются с исходными обозначениями; вместимость, этажи и специальности не придумываются. Для внутренних связей используется общая запись «Колледж», без публичного разделения по корпусам.

Пустые оформленные области за пределами данных не учитываются: например, сохранённая Excel ширина до столбца IU не мешает загрузке таблицы, реально занимающей 89 столбцов. Исходный файл не меняется. Ограничения 10000 строк / 200 столбцов проверяются по содержимому, включая формулы; сохраняются ограничения размера файла и распакованного XLSX. Названия групп со скобками (например, `ИСр(к)-9-25`) сохраняются полностью.

Файл заменяет только свои группы: остальные курсы продолжают действовать. Повторная загрузка тех же байтов файла на тот же период не создаёт дубликаты. Исключение — переход со старой ревизии парсера: разрешён один повторный импорт с предпросмотром и подтверждением новой версии. Пары начинаются с 09:00, в понедельник четвёртая — с 14:50; своё время редактируется в админке. «Разговоры о важном» и прежнее название «Кураторский час» — одно событие без номера пары, вне списка дисциплин. Строка перед первой парой задаёт первую смену (08:20–08:55), после третьей — вторую (14:15–14:45). Строки перед заголовком понедельника относятся к следующему понедельнику и его неделе, включая начало первого блока.

## Замены из изображений

Загрузка — `/admin/schedule/imageimport/upload/`. Укажите дату и формат: «Таблица замен» или «Жёлтые ячейки». В первом формате «По расп» и «−» пропускаются: знак «−» означает изначальное отсутствие пары. Во втором учитываются только жёлтые области.

OCR выполняется локально: Windows OCR с русским языком либо Tesseract `rus+eng` на Linux. Изображения не отправляются сторонним сервисам. Форматы PNG/JPEG/WebP, до 10 МБ и 16 мегапикселей.

Распознавание использует увеличенные ячейки, удаление сетки и контекст расписания группы. Сначала определяется группа, затем её предметы и преподаватели за обе недели. Исходное занятие выбирается строго по дате замен и её учебной неделе; номер недели виден в шапке проверки. Для кабинетов сначала учитываются полные прочитанные обозначения и типичные ошибки OCR, затем контекст выбранной дисциплины, преподавателя и нужной недели. Неполное «11» не считается точным чтением «411»; неоднозначные номера и суффиксы отмечаются. Для повреждённых слов предлагается ближайшее совпадение; неразобранные преподаватель и кабинет могут быть дополнены из расписания. Пометка «Подобрано» объясняет предположение и показывает эвристическую оценку. Если группы или её справочника нет, поля могут остаться пустыми. Группы другого года не подставляются.

До 12 неуверенных ячеек (бюджет второго прохода — 25 секунд) дополнительно распознаются отдельно от соседей с увеличением и контрастом. Координаты ячейки и строки сохраняются в предварительном импорте. «Фрагмент» показывает увеличенную ячейку, «Строка целиком» — её контекст; для догадок фрагмент раскрыт сразу. Кнопка «Распознать повторно» доступна до публикации и сбрасывает несохранённые правки формы. Оригинал и фрагменты доступны автору загрузки и администратору, с теми же правами и CSRF для повторного анализа.

На странице проверки рядом с оригиналом исправьте группу, подгруппу, пару, предмет, преподавателя и кабинет, отметьте проверенные строки и опубликуйте. Поля со справочниками имеют поиск внутри выпадающего списка. Проверки автоматически не проставляются; низкое разрешение может потребовать ручных исправлений. Отмена выбирается явно. Публикация набора атомарна и проверяет конфликты, включая обмен кабинетами и независимые замены подгрупп. При ошибке отображаются номера строк, обе группы, предметы, преподаватели и время. Для намеренных пересечений доступны независимые галочки «Оставить пересечение кабинета» и «Оставить пересечение преподавателя». Каждое разрешение действует только для конкретных занятий на выбранную дату. При совпадении обоих ресурсов нужны обе галочки. Пересечения группы и недоступность кабинета не пропускаются. На дату практики новая замена не публикуется. До подтверждения публичное расписание не меняется. Оригиналы доступны только сотрудникам.

## Стандартный профиль

Первая строка — заголовки. Один ряд — одно регулярное занятие и один участник. Полностью пустые строки пропускаются; значения объединённых ячеек распространяются на весь диапазон. Формулы отклоняются: вставьте вычисленные значения перед загрузкой.

| Заголовок | Формат |
|---|---|
| День | 1–7 (понедельник–воскресенье) или русское полное название |
| Пара | Номер из справочника звонков |
| Группа | Точное название из справочника |
| Подгруппа | Название внутри группы; пусто — вся группа |
| Дисциплина | Название из справочника |
| Преподаватель | Полное отображаемое имя из справочника |
| Корпус | Название из справочника |
| Аудитория | Номер внутри указанного корпуса |
| Неделя | `all`, `odd`, `even`; пусто — каждая |
| Тип | Произвольное описание занятия |
| Начало / Окончание | Необязательно, оба поля, текст `HH:MM`; иначе время пары |

Обязательны первые семь полей кроме подгруппы: День, Пара, Группа, Дисциплина, Преподаватель, Корпус, Аудитория. Сопоставление нечувствительно к регистру и лишним пробелам, но не является нечётким поиском. Неоднозначные записи блокируют подтверждение.

Этот общий профиль предназначен для заранее нормализованных таблиц с существующими справочниками.

Повторяющиеся строки считаются ошибкой. Одинаковые занятия разных участников с одними ресурсами объединяются в совместное занятие. Разные занятия подгрупп задавайте разными строками с различающимися ресурсами/дисциплинами.

## Свои заголовки

Создайте профиль «Строки с заголовками», поле сопоставления:

```json
{
  "header_row": 2,
  "columns": {
    "day": "День недели",
    "slot": "№ пары",
    "group": "Учебная группа",
    "subject": "Предмет",
    "teacher": "ФИО",
    "building": "Здание",
    "room": "Кабинет"
  }
}
```

Внутренние ключи: `day, slot, group, subgroup, subject, teacher, building, room, week, type, start, end`. Для неуказанных ключей действуют стандартные заголовки.

## Блоки групп

Профиль «Блоки групп» задаёт индексы строк и столбцов, начиная с 1:

```json
{
  "group_row": 1,
  "data_row": 3,
  "day_column": 1,
  "slot_column": 2,
  "blocks": [
    {
      "group_column": 3,
      "building": "Корпус 1",
      "columns": {"subject": 3, "teacher": 4, "room": 5, "subgroup": 6}
    },
    {
      "group_column": 7,
      "building": "Корпус 1",
      "columns": {"subject": 7, "teacher": 8, "room": 9, "subgroup": 10}
    }
  ]
}
```

Группа читается из `group_row/group_column`. День и пара — из общих столбцов. Полностью пустые блоки пропускаются. Профиль применяется ко всем листам файла: удалите титульные и вспомогательные листы перед загрузкой.

Для предоставленного исходного файла используйте специальный профиль колледжа выше. Настраиваемый профиль блоков оставлен для других структур. PDF не поддерживается; изображения замен обрабатываются отдельным модулем.

## Порядок и гарантии

1. Выберите файл, профиль, период и даты действия.
2. Просмотрите строки с сопоставленными справочниками, количество групп, прежнее/новое количество занятий, ошибки и конфликты.
3. Исправьте справочник или исходный файл и загрузите снова, если есть ошибки. Можно отменить предварительный импорт.
4. Подтвердите публикацию. Сервер повторно проверяет весь диапазон и сохраняет новую версию в одной транзакции. При ошибке ни занятия, ни версия не публикуются.

Общие профили строк/блоков создают полную версию на указанные даты. Специальный профиль колледжа заменяет только группы из файла. Прежние версии сохраняются для отката. Подтверждение одного импорта идемпотентно.

Ограничения: XLSX до 10 МБ, распакованные данные до 50 МБ, до 1000 ZIP-элементов, 10000 строк и 200 столбцов на лист, 5000 записей за импорт. Первые 100 конфликтов показываются в предпросмотре; подтверждение всё равно проверяет период и прекращается на первом конфликте. Предпросмотр не пишет расписание в БД (временные данные создаются в транзакции с принудительным откатом).

## Восстановление старых кураторских часов

Предпочтительный путь — заново загрузить исходный файл курса через админку и подтвердить новую версию. При этом проверьте будущие замены: они привязаны к занятиям старой версии.

Для точечного исправления старого импорта без смены идентификаторов обычных пар:

```bash
python manage.py backup_db
python manage.py repair_class_hours "/path/to/1 курс.xlsx" --batch 5 --restore-missing-groups
```

Номер импорта берётся из админки. Команда сверяет SHA-256 с подтверждённым импортом и пересоздаёт его события с номером 0. Необязательный `--restore-missing-groups` дополнительно восстанавливает обычные пары групп, целиком пропущенных старым импортом (например, названия со скобками). Существующие обычные занятия и статусы групп сохраняются; совместные пары получают новых участников без дублирования. С восстановлением пар проверяются конфликты по всем датам версии, ошибка откатывает всю операцию. Действие записывается в журнал. Чужой или изменённый файл отклоняется. При существующих заменах кураторских часов команда останавливается: используйте новую версию. Повторный запуск не размножает занятия. Команда предназначена для администратора сервера; перед запуском сделайте резервную копию.
