# Расписание колледжа

Открытая информационная система расписания и мониторинга занятости учебных аудиторий. Публичный просмотр не требует регистрации; публикация данных доступна сотрудникам через административную панель.

## Локальный запуск в Windows

Требуются Python 3.13 или 3.14 и Git. Node.js нужен только для необязательной проверки синтаксиса JavaScript; сборки frontend нет.

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe manage.py seed_demo
.\venv\Scripts\python.exe manage.py createsuperuser
.\venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Откройте [сайт](http://127.0.0.1:8000) и [панель управления](http://127.0.0.1:8000/admin/). Пароль администратора задаётся вами; общих паролей в проекте нет. Демонстрационные данные создаются относительно текущего учебного года и могут загружаться повторно.

Для последующих запусков: ` .\start.ps1`. Скрипт устанавливает зависимости, применяет миграции и запускает сервер. Активация виртуального окружения не требуется. На Linux/macOS используйте `python3 -m venv venv` и `venv/bin/python` вместо пути Windows.

## Возможности

- Поиск групп и преподавателей, включая кириллицу и инициалы; фильтры групп по курсу, специальности, корпусу и учебному году.
- Расписание на дату, сегодня, завтра и неделю; подсветка текущего и следующего занятия; ссылки между группами, преподавателями и аудиториями.
- Избранное в браузере, сохранение фильтров в URL, копирование ссылки.
- Занятость помещений по точному интервалу и паре, фильтры по корпусу, этажу, типу и вместимости; карточки и сетка по парам.
- Замены, отмены, переносы, дополнительные занятия, изменения подгрупп; исходное занятие сохраняется.
- Черновики, предпросмотр, публикация с блокировкой конфликтов и безопасный отзыв публикации.
- Полные версии расписания, чётные/нечётные недели, праздники и нестандартные учебные дни.
- XLSX: профили строк и блоков групп, объединённые ячейки, проверка справочников, предпросмотр и атомарная публикация; откат версии.
- Смена учебного года с предварительным просмотром состава групп, архивные расписания.
- Права диспетчера по корпусам, журнал действий, настройки и резервное копирование.

## Технологии и структура

Python / Django 5.2 LTS, SQLite локально, PostgreSQL на сервере, HTML/CSS/JavaScript без сборщика. Стек в исходном ТЗ был рекомендательным; Django выбран ради встроенных миграций, сессий, CSRF, ролей и административного интерфейса.

| Путь | Назначение |
|---|---|
| `schedule/models.py` | Реляционная модель данных |
| `schedule/services.py` | Расчёт расписания, конфликты, публикация, учебные годы |
| `schedule/importing.py` | Парсеры XLSX, сопоставление и транзакционный импорт |
| `schedule/views.py` | Публичный и административный JSON API |
| `schedule/admin.py` | Административные сценарии и права |
| `static/`, `templates/` | Публичный интерфейс и административные шаблоны |
| `schedule/tests.py` | Автоматические проверки критических правил |
| `docs/` | Инструкции и описание архитектуры |

## Проверки

```powershell
.\venv\Scripts\python.exe manage.py test
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe manage.py makemigrations --check --dry-run
node --check static/app.js
```

`DEBUG=1` включён по умолчанию только для локального запуска. Инструкции HTTPS и PostgreSQL находятся в документации развёртывания. Реального образца расписания колледжа в исходных материалах не было: универсальное распознавание произвольной таблицы не обещается; используйте стандартный формат либо настройте профиль блоков.
