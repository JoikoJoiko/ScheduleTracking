# Расписание колледжа

Открытая информационная система расписания и мониторинга занятости учебных аудиторий. Публичный просмотр не требует регистрации; публикация данных доступна сотрудникам через административную панель.

## Локальный запуск в Windows

Требуются Python 3.13 или 3.14 и Git. Node.js нужен только для необязательной проверки синтаксиса JavaScript; сборки frontend нет.

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe manage.py createsuperuser
.\venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Откройте [сайт](http://127.0.0.1:8000) и [панель управления](http://127.0.0.1:8000/admin/). В текущей локальной БД создан тестовый вход `admin / admin` по запросу пользователя. Эта учётная запись не создаётся миграциями и не переносится на хостинг вместе с кодом.

В интерфейсе по умолчанию включена тёмная тема; кнопка в правом верхнем углу переключает оформление. Выбор сохраняется в браузере. В публичных фильтрах нет корпусов и вместимости, курсы ограничены диапазоном 1–4.

Звонки уже заполнены: 08:00–09:30, 09:40–11:10, 11:40–13:10, 13:20–14:50, 15:00–16:30, 17:00–18:30, 18:40–20:10. Редактирование — раздел «Звонки» в админке; просмотр — `/bells`.

Для последующих запусков: ` .\start.ps1`. Скрипт устанавливает зависимости, применяет миграции и запускает сервер. Активация виртуального окружения не требуется. На Linux/macOS используйте `python3 -m venv venv` и `venv/bin/python` вместо пути Windows.

## Возможности

- Поиск групп и преподавателей, включая кириллицу и инициалы; фильтры групп по курсу и учебному году.
- Расписание на дату, сегодня, завтра и неделю; подсветка текущего и следующего занятия; ссылки между группами, преподавателями и аудиториями.
- Избранное в браузере, сохранение фильтров в URL, копирование ссылки.
- Занятость кабинетов по точному интервалу и паре; карточки и сетка по парам.
- Замены, отмены, переносы, дополнительные занятия, изменения подгрупп; исходное занятие сохраняется.
- Черновики, предпросмотр, публикация с блокировкой конфликтов и безопасный отзыв публикации.
- Первая и вторая недели с настраиваемым опорным понедельником и видимым номером текущей недели; праздники и нестандартные учебные дни.
- Общие звонки и отдельные интервалы по дням недели. Время одинаково рассчитывается в расписании, заменах и занятости кабинетов.
- Вкладка «Дисциплины»: предметы и преподаватели группы за выбранный учебный период. Сокращения в заменах подбираются по этому же списку, включая обе недели.
- XLSX колледжа: две недели, строки дисциплин/преподавателей, подгруппы и обозначения кабинетов. Курсы загружаются независимо и накапливаются. Также поддерживаются настраиваемые профили строк и блоков.
- Замены из изображений: обычная таблица или только жёлтые ячейки; локальный OCR, проверка каждой строки и атомарная публикация. «По расп» и «−» не меняют расписание.
- Смена учебного года с предварительным просмотром состава групп, архивные расписания.
- Права диспетчера по корпусам, журнал действий, настройки и резервное копирование.

## Технологии и структура

Python / Django 5.2 LTS, SQLite локально, PostgreSQL на сервере, HTML/CSS/JavaScript без сборщика. Стек в исходном ТЗ был рекомендательным; Django выбран ради встроенных миграций, сессий, CSRF, ролей и административного интерфейса.

| Путь | Назначение |
|---|---|
| `schedule/models.py` | Реляционная модель данных |
| `schedule/services.py` | Расчёт расписания, конфликты, публикация, учебные годы |
| `schedule/importing.py` | Парсеры XLSX, сопоставление и транзакционный импорт |
| `schedule/views.py` | Публичный и административный JSON API |
| `schedule/admin.py` | Административные сценарии и права |
| `static/`, `templates/` | Публичный интерфейс и административные шаблоны |
| `schedule/tests.py` | Автоматические проверки критических правил |
| `docs/` | Инструкции и описание архитектуры |

Загрузка — основная часть главной страницы `/admin/`: четыре карточки курсов и отдельный блок изображений замен. Выберите или перетащите XLSX в карточку нужного курса и нажмите «Загрузить и обновить». Система сверит курс с содержимым, разберёт файл и опубликует его при успешной проверке. Конфликты оставляют файл на проверке; режим автоматической публикации можно отключить. Обработка и история обновляются без перезагрузки страницы. Другие курсы сохраняются.

Локально уже загружен предоставленный файл четвёртого курса. Реальные исходные таблицы, изображения и база не включаются в Git. Демо-генератор удалён.

Замены: `/admin/schedule/imageimport/`. Оба предоставленных скриншота сохранены в локальной БД для проверки; публикация происходит после выбора проверенных строк. Для OCR на Windows нужен русский языковой пакет распознавания, на Linux — Tesseract с `rus+eng` (включён в Dockerfile). Низкое разрешение скриншота может потребовать ручного заполнения полей.

## Проверки

```powershell
.\venv\Scripts\python.exe manage.py test
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe manage.py makemigrations --check --dry-run
node --check static/app.js
```

`DEBUG=1` включён по умолчанию только для локального запуска. Инструкции HTTPS и PostgreSQL находятся в документации развёртывания. Специальный профиль проверен на предоставленном реальном XLSX; распознавание произвольного оформления Excel не обещается.
